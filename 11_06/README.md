추후 수정하여 8_6_1 제작

🛠️ 1. 안전성 및 버그 수정 (1~5번)
1. 배열 인덱스 초과(Buffer Overflow) 방지: 블록 좌우 좌표가 경계선을 넘을 때 배열 크기를 초과하여 메모리를 침범하는 오류를 엄격한 조건문(>=, <)으로 차단했습니다.

2. 키 꾹 누름 꼼수 방지 (ClearInputBuffer): 스페이스바를 꾹 누르고 있어도 다음 턴이 자동으로 스킵되거나 연속 입력되는 현상을 막기 위해 입력 버퍼를 비우는 로직을 추가했습니다.

3. 잘못된 좌표 보정: 블록의 시작 및 이동 좌표가 음수(-) 영역으로 이탈하지 않도록 안전 장치를 마련했습니다.

4. 난수 생성 초기화 (srand): 게임 실행 시마다 매번 똑같은 패턴이 아니라 완전히 무작위로 시작하도록 time(NULL) 기반의 시드 값을 설정했습니다.

5. 메모리 안정성 확보: 전역 배열 block_stack의 크기를 넉넉하게 확장하여 메모리 오염 가능성을 원천 차단했습니다.

🎮 2. 게임 규칙 및 진행 방식 변화 (6~11번)
6. 게임 오버(Game Over) 조건 신설: 기존에는 무조건 15번을 채워야 끝났지만, 블록이 천장에 닿으면 즉시 게임이 종료되도록 규칙을 바꿨습니다.

7. 랭킹(최고 기록) 시스템 도입: 세션 내에서 달성한 최고 점수(최고 높이)를 기억하고 화면에 갱신해 줍니다.

8. 게임 종료 후 리트라이(Retry) 기능: 게임이 끝나도 프로그램이 꺼지지 않고, Y / N 키를 눌러 곧바로 새 게임을 시작할 수 있습니다.

9. 시도 횟수 및 실시간 상태 표시: 현재 몇 번째 시도인지, 남은 기회는 얼마나 되는지 우측 정보란에 명확하게 표기되도록 구조를 다듬었습니다.

10. 결과 판정 분기 추가: 천장에 닿아서 게임 오버가 되었는지, 혹은 기회를 모두 완주해서 끝났는지를 구분하여 서로 다른 메시지를 출력합니다.

11. 안내 인트로 화면 리뉴얼: 게임 시작 전 조작법과 변경된 규칙(꼼수 방지, 랜덤 시작 등)을 보기 좋게 안내하도록 수정했습니다.

📐 3. UI, 레이아웃 및 시인성 개선 (12~20번)
12. 칸 간격(Alignment) 완벽 정렬: 테두리 격자와 내부 블록이 움직이는 x 좌표의 짝수 간격을 딱 맞추어, 벽을 뚫고 나가거나 어긋나던 현상을 해결했습니다.

13. 텍스트 컬러(SetConsoleTextAttribute) 도입: 콘솔 글자에 색상을 입혀서 단순 흑백 화면보다 시인성을 대폭 끌어올렸습니다.

14. 움직이는 블록 색상 변경: 좌우로 움직이는 블록의 색상을 청록색(Cyan)으로 지정하여 눈에 띄게 만들었습니다.

15. 낙하 중인 블록 애니메이션 색상: 위에서 아래로 뚝 떨어질 때는 초록색으로 시각적인 타격감을 주도록 했습니다.

16. 안착된 블록 고유 색상: 바닥이나 다른 블록 위에 완전히 쌓인 블록은 노란색으로 고정되어 쌓인 모양이 한눈에 들어오게 했습니다.

17. 우측 정보란 색상 분할: 시도 횟수, 목표 높이, 쌓인 높이 등의 UI 텍스트에 각각 다른 색상을 부여해 가독성을 높였습니다.

18. 인트로 화면 컬러 디자인: 게임 타이틀과 안내 문구에 하늘색과 노란색 포인트를 주어 밋밋함을 없뎠습니다.

19. 게임 오버/성공 메시지 강조: 게임이 끝났을 때 뜨는 결과 안내문에 💀, 🎉 같은 직관적인 아이콘과 색상을 적용했습니다.

20. 화면 깜빡임(Flickering) 최소화: 불필요한 전체 화면 갱신을 줄이고 변경되는 좌표 부근만 실시간으로 지우고 그리도록 정돈했습니다.

⚙️ 4. 코드 구조 및 유지보수성 향상 (21~30번)
21. 함수 이름 표준화 (파스칼 케이스): 기존의 뒤죽박죽이던 함수 이름들을 IntroGame, PlayGame, DrawRectangle, Gotoxy 형태로 깔끔하게 통일했습니다.

22. 매크로 상수 대문자화 (BOX_WIDTH, BOX_HEIGHT): 코드 전반에 걸쳐 사용되는 상수를 직관적인 대문자 매크로로 정의하여 유지보수성을 높였습니다.

23. 모듈화 강화 (PlayGame 함수 분리): 게임 플레이 전체 로직을 독립된 함수로 분리하여 반복 실행(리트라이) 구조를 쉽게 구현할 수 있게 만들었습니다.

24. 포인터 인자를 통한 점수 반환: PlayGame(int *scoreOut) 구조를 도입해 게임 안에서 얻은 최종 점수를 메인 함수로 안전하게 전달하도록 설계했습니다.

25. 독립된 입력 버퍼 관리 함수 (ClearInputBuffer): 입력 처리를 전용 함수로 분리하여 코드의 가독성을 높이고 디버깅이 쉽도록 만들었습니다.

26. 최고 높이 계산 전용 함수 (GetMaxBlockHeight): 현재 가장 높이 쌓인 블록을 계산하는 로직을 별도의 함수로 독립시켜 재사용성을 극대화했습니다.

27. 전역 변수 의존도 최소화: 필요한 상태 값들을 함수의 매개변수와 지역 변수로 적절히 나누어 관리하도록 개선했습니다.

28. 윈도우 API 핸들 최적화 (GetStdHandle): 커서 이동 및 색상 변경 시 반복 호출되는 시스템 핸들 요청 코드를 깔끔하게 정돈했습니다.

29. 예외 입력 처리 (Y/N 판정): 게임 종료 후 재시도 여부를 물어볼 때 대소문자(y, Y, n, N)를 모두 인식하도록 유연하게 처리했습니다.

30. 전체 주석 보강 및 코드 포맷팅: 초보자도 어느 부분이 어떤 역할을 하는지 쉽게 이해할 수 있도록 핵심 로직마다 주석을 상세히 달아두었습니다.
